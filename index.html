Nova — Trợ lý thông minh cho Discord.

Chat với AI, quản lý cộng đồng, tạo War, Backup, Event và nhiều hơn nữa — ngay trong Discord.

Mời Nova → Khám phá tính năng
Tính năng

Tính năng mạnh mẽ.

Tất cả những gì Nova có thể làm — từ AI cho tới moderation.

🤖

AI Chatbot

Trò chuyện với AI ngay trong Discord. Hỗ trợ persona, lịch sử riêng từng người hoặc dùng chung cho cả kênh. Được hỗ trợ bởi Qwen3.7-max.

/chat /persona /clearchat
🎨

AI Image

Tạo hình ảnh bằng AI ngay trong Discord từ một câu mô tả ngắn.

/image
⚔️

War Ping / Backup Ping

Gọi người tham gia War hoặc yêu cầu Backup nhanh chóng, có thread riêng, phân quyền End rõ ràng.

/end all
🏆

Event

Tạo event trong server với panel tham gia, quản lý danh sách và công bố kết quả.

/event
☠️

Ban Zone

Hệ thống Ban Zone và moderation cho server. Hỗ trợ mode ban hoặc mute, whitelist riêng theo từng server.

/banzone /setbanchannel /banwhitelist /bandebug
🛡️

Moderation

Các công cụ moderation dành cho server: ban, unban, mute, unmute.

/ban /unban /mute /unmute
ℹ️

Server Information

Xem thông tin bot, server và user ngay trong Discord.

/info /serverinfo /userinfo
🔐

Admin / Configuration

Cấu hình help channel, ping role, trusted users, Ban Zone và quản lý AI/API.

/config /trust
Lệnh chính

Lệnh chính

Những lệnh slash bạn sẽ dùng nhiều nhất khi chạy Nova.

/chatChat với AI
/imageTạo ảnh bằng AI
/banBan user
/unbanGỡ ban
/muteTimeout user
/unmuteGỡ timeout
/banzoneCấu hình Ban Zone
/banwhitelistQuản lý whitelist
/infoThông tin bot
/serverinfoThông tin server
/userinfoThông tin user
/end allKết thúc toàn bộ War/Backup
